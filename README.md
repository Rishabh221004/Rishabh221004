### 🚀 Featured Projects

**AI-Powered Data Analysis Automation Agent** &nbsp; [Repo →](https://github.com/Rishabh221004/ai-data-analysis-automation-agent)
*An autonomous GPT-4.1 agent that writes and executes its own Python to deliver statistical insights across 8+ file formats (CSV, JSON, DB, Parquet) in under 60 seconds.*
- Built a **self-healing execution loop** — 3-retry logic with automated error parsing — hitting a 95% success rate on unsupervised code runs
- Engineered an **ethical, rate-limited scraping pipeline** (BeautifulSoup + Playwright + robots.txt compliance) across 15+ dynamic and static sources, cutting scraping failures by 40%
- Architected a **FastAPI REST layer** orchestrating 27+ data libraries (Pandas, SciPy, GeoPandas) with multipart upload handling for real-time processing
- Shipped an **auto-visualization pipeline** producing optimized (<100KB) graphs via Matplotlib and NetworkX, embedded directly in API responses
- **Stack:** Python · FastAPI · GPT-4.1 · Pandas · SciPy · GeoPandas · Playwright

**PPT Generation — Auto Presentation Builder** &nbsp; [Repo →](https://github.com/Rishabh221004/PPTGeneration)
*Paste raw text or markdown, upload your own template, and get back a fully branded `.pptx` — no design work required.*
- Template-aware generation that respects the uploaded `.pptx`/`.potx`'s fonts, colors, and layouts via placeholders
- **BYO LLM key** (OpenAI / Anthropic / Gemini) — keys are never stored or logged
- LLM-driven slide splitting and bulleting with strict **JSON-structured output** for reliable parsing
- Intelligently reuses images already present in the source template across generated slides
- **Stack:** Python · FastAPI · GPT-4 · Gemini API

**LLM Agent — Proof of Concept** &nbsp; [Repo →](https://github.com/Rishabh221004/LLM-Agent-Proof-of-Concept)
*A sleek, dark-themed chat interface prototype built for fluid AI-powered conversations.*
- Modern gradient-styled UI with clearly distinguished user/assistant message bubbles
- Smooth animations and hover interactions layered on a fully responsive layout across devices
- **Stack:** Python · FastAPI · HTML/CSS/JS · Bootstrap

**Smart CivicConnect — AI Civic Issue Detection Platform** *(semester project)*
*A platform for detecting and intelligently routing civic issues, designed end-to-end from spec to interactive prototype.*
- Produced a professionally designed system document via ReportLab alongside a 10-screen interactive UI wireframe
- Backend built on FastAPI + PostgreSQL with Gemini/OpenAI API integration for issue classification
